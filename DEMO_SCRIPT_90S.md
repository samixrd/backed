## Recording rules

- Record each beat separately and stitch them in CapCut. Nobody nails a ninety-second single take on the first try.
- Run the MCP query ten minutes before recording so the cache is warm. If the terminal dies mid-take, drop in the B-roll frame and move on.
- The radar refreshes every sixty seconds, so SOL might not be on it when you record. The line already says "click SOL, and you get..." so just click the top card if needed.
- Read the voice lines out loud twice before recording. If any sentence trips your tongue, shorten it. Nobody notices a shorter sentence; everybody notices a stumble.
